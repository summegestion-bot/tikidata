# Tiki Data — El fútbol en datos

App de información de fútbol creada por Teo. Datos de football-data.org (plan gratuito) y titulares de portales deportivos.

## Publicar en Render
- Tipo: Web Service · Plan: Free
- Build command: `pip install -r requirements.txt`
- Start command: `python app.py`
- Variable de entorno: `FOOTBALL_DATA_KEY` = la clave de football-data.org

## Probar en la compu
```
set FOOTBALL_DATA_KEY=tu_clave
py app.py
```
